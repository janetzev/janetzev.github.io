Om projektet

Wigell Car Rental är en webbaserad biluthyrningsapplikation där användare kan se tillgängliga fordon och skapa bokningar. Applikationen innehåller även administrativa funktioner för att hantera fordon, användare och bokningar.


Projektet är byggt för att efterlikna ett verkligt bokningssystem och innehåller både ett vanligt användarläge och ett särskilt administratörsläge.

🚗 Fordon

Användaren kan se vilka fordon som finns tillgängliga, läsa information om dem och välja ett fordon att boka.

Applikationen

Fordon

Översikt över de fordon som finns tillgängliga för uthyrning.

Bokningar

Översikt över användarnas bokningar och deras status.

Administrationssystem

Administrationsdelen ger möjlighet att hantera systemets centrala data. Administratören kan bland annat skapa, uppdatera och ta bort fordon samt hantera användare och bokningar.


Fordonshantering

Administratören kan ändra fordonsinformation, priser och bokningsstatus.

Användarhantering

Användare kan administreras och deras roller hanteras från adminvyn.

Bokningshantering

Administratören kan se systemets bokningar och hantera deras status.

EPA Mode

Ett särskilt EPA Mode är implementerat som förändrar applikationens visuella uttryck och visar ett alternativt tema för systemet.


Funktionen demonstrerar hur samma applikation kan presentera olika visuella lägen samtidigt som den bakomliggande funktionaliteten finns kvar.
