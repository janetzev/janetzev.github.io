Fullstack Web Application

Wigell Car Rental

Ett fullstack-projekt för biluthyrning där användare kan se tillgängliga fordon, skapa bokningar och hantera sina bokningar. Administratörer kan dessutom hantera fordon, användare och bokningar genom ett separat administrationsgränssnitt.

Om projektet

Wigell Car Rental är en webbaserad biluthyrningsapplikation. Projektet är byggt för att hantera hela uthyrningsflödet från att en användare väljer ett fordon till att bokningen skapas och kan administreras.

Applikationen innehåller både ett användargränssnitt och ett administrativt gränssnitt. Fokus ligger på att skapa ett tydligt bokningsflöde samtidigt som administratören får kontroll över systemets data.

Funktioner

🚗 Fordon

Användaren kan se vilka fordon som finns tillgängliga, läsa information om bilen och välja ett fordon att boka.

📅 Bokningar

Användare kan skapa bokningar genom att välja start- och slutdatum. Systemet beräknar därefter det totala priset.

👤 Användare

Systemet hanterar användarkonton och roller med separata rättigheter för vanliga användare och administratörer.

⚙️ Administration

Administratören kan hantera fordon, användare och bokningar från administrationsgränssnittet.

Fordon

Fordonssidan presenterar de bilar som finns i systemet. Varje fordon visas som ett kort med bild, modell, typ, egenskaper och pris per dag.

Bokningar

Bokningsdelen visar användarens aktuella och avslutade bokningar. För varje bokning visas bland annat fordon, datum, status och totalpris.

Administration

Administrationsdelen ger möjlighet att hantera systemets fordon. Administratören kan bland annat ändra information, pris och bokningsstatus.

Användarhantering

Administratören kan se registrerade användare och hantera deras information och roller.

EPA MODE

Projektet innehåller även ett alternativt visuellt tema, EPA MODE. När läget aktiveras ändras applikationens färger, typografi och visuella uttryck.

EPA MODE är byggt som en del av applikationens befintliga gränssnitt och kan växlas direkt från navigeringen.
